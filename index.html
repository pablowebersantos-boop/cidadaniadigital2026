04 — Princípios

Manifesto
do Código Cívico

  1. I

    Transparência não é opcional.

    Todo sistema que toma ou influencia decisões sobre vidas humanas deve ser auditável, explicável e contestável.

  2. II

    Acesso é um direito, não um privilégio.

    Ferramentas de IA devem ser construídas para todos — com suporte a múltiplas línguas, baixo consumo de dados e interfaces acessíveis.

  3. III

    Dados públicos pertencem ao público.

    Dados coletados pelo Estado devem ser abertos, documentados e utilizados para o bem comum — nunca como mercadoria.

  4. IV

    Código aberto é ato político.

    Compartilhar conhecimento é resistir à concentração de poder. Open-source é infra-estrutura democrática.
